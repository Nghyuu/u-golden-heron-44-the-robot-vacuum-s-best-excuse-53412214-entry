The funniest one-line excuse a robot vacuum gives for missing a spot — a cliff sensor that saw a dark rug edge and filed the whole corner as a staircase. Entry for the [make.fun bounty](https://make.fun/bounty/u-golden-heron-44-the-robot-vacuum-s-best-excuse-53412214).

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts
cat /tmp/out/entry.txt
```

`main.ts` copies the committed line from `entry.txt` to `$MAKEFUN_OUTPUT_DIR/entry.txt`, byte for byte, using only the Node standard library.
